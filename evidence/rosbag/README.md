# Evidências ROS 2 bag

Esta pasta destina-se às gravações integradas produzidas com `ros2 bag`.

Tópicos previstos:

- `/vision/canvas_png`
- `/vision/image`
- `/vision/command`
- `/turtle1/cmd_vel`
- `/turtle1/pose`
- `/rosout`

As gravações permitem reproduzir e inspecionar a comunicação entre a
interface web, o nó de visão, a Behavior Tree e o Turtlesim.

Uma gravação só deve ser apresentada como evidência depois de ter sido
efetivamente criada e validada com `ros2 bag info`.
